# Custom Affiliate System v1.0.8

Complete WordPress affiliate management system with configurable tiers, commission tracking, and automated payouts.

## 🎯 What's New in v1.0.8

### ⚙️ Dynamic Settings System
- **Configurable Tiers**: Manage commission rates, payout minimums, and payment timelines from WordPress admin
- **No Code Required**: All settings adjustable through intuitive admin interface
- **Auto-Update**: Changes instantly apply to all existing affiliates and coupons

### 📧 Email Communication System
- **Mass Emails**: Send announcements to all affiliates or specific tiers
- **Personalization**: Auto-include affiliate codes, tier info, and commission rates
- **Professional Templates**: Beautiful HTML email templates with your branding

### 🐛 Debug System (Optional)
- **Troubleshooting**: Enable debug mode to track all affiliate actions
- **Activity Log**: View detailed logs of registrations, commissions, and payouts
- **Performance**: Disable when not needed to maintain optimal speed

### 🎨 Enhanced Admin UI
- Modern gradient designs and intuitive layouts
- Real-time validation and helpful descriptions
- Mobile-responsive admin pages

## 📦 Features

### Tier Management
- **Tier I (Basic)**: 10% commission, 20€ minimum payout, 30-day processing
- **Tier II (Influencer)**: 15% commission, no minimum, 3-day processing
- **Ambassador**: 20% commission, no minimum, 3-day processing

### Automated Systems
- Auto-generate unique affiliate codes on user registration
- Auto-create WooCommerce coupons with configurable discounts
- Track commissions automatically on order completion
- Email notifications for affiliates and admins

### Dashboard Features
- Modern influencer dashboard in WooCommerce My Account
- Real-time commission tracking
- Payout request system with multiple payment methods
- Sales history and performance metrics

## 🔧 Requirements

- WordPress 5.8+
- WooCommerce 5.0+
- PHP 7.4+

## 📖 Quick Start

1. Install and activate plugin
2. Go to **Affiliates → Settings**
3. Configure commission rates and payment terms
4. Set support email for notifications
5. Done! New user registrations auto-create affiliates

## ⚙️ Configuration

### Basic Setup
Navigate to **Affiliates → Settings** to configure:

- **Commission Rates**: Set percentage per tier (0-100%)
- **Minimum Payouts**: Set minimum withdrawal amounts
- **Payment Timeline**: Days to process approved payouts
- **Coupon Discounts**: Customer discount when using affiliate codes
- **Currency Symbol**: € $ £ etc.
- **Support Email**: Where payout requests are sent
- **Auto-Approve**: Enable/disable automatic affiliate approval

### Email System
Use **Affiliates → Email Affiliates** to:
- Send updates to all affiliates or specific tiers
- Include personalized tier information
- Track sent/failed emails

### Debug Mode
Enable in Settings to:
- Track all affiliate system actions
- View detailed logs in **Affiliates → Debug Log**
- Troubleshoot commission tracking issues
- Remember to disable after troubleshooting

## 📊 Admin Pages

- **Overview**: View all affiliates, stats, upgrade tiers
- **Payouts**: Manage withdrawal requests, approve payments
- **Reports**: Analytics, top performers, export data
- **Settings**: Configure all system parameters
- **Email Affiliates**: Send mass communications
- **Debug Log**: View system activity (when debug enabled)
